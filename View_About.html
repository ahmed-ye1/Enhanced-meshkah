مِشكاة (الباحث الإسلامي)

أداة متكاملة لطلبة العلم والباحثين لإدراج الآيات القرآنية وتفاسيرها، الأحاديث النبوية وشروحاتها، واقتباسات من الكتب الشرعية مع التوثيق العلمي الدقيق.

المصادر والتقنيات المستخدمة (APIs):
  • القرآن الكريم: Alquran.Cloud API.
  • التفاسير: Quran-Tafseer API و Quran.com.
  • الأحاديث النبوية: HadithAPI (الكتب الستة وغيرها) وموسوعة الدرر السنية.
  • الكتب الشرعية: Turath API (مكتبة تراث للبحث والاستخراج).
📌 تنبيه أكاديمي حول الترقيم:
يوجد اختلاف في أرقام بعض الأحاديث نظراً لاختلاف الطبعات؛ حيث تعتمد الدرر السنية على الترقيم الكلاسيكي (مثل ترقيم محمد فؤاد عبد الباقي وفتح الباري)، بينما يعتمد HadithAPI على ترقيم طبعة دار السلام.
