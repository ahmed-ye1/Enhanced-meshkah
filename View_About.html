إضافة مِشكاة (الباحث الإسلامي)

أداة مخصصة لطلبة العلم الشرعي لإدراج الآيات القرآنية والتفاسير والأحاديث النبوية وشروحاتها مع التوثيق العلمي الدقيق .

المصادر والتقنيات المستخدمة (APIs):
  • القرآن الكريم: Alquran.Cloud API.
  • التفاسير : Quran-Tafseer API (التفاسير العربية).
  • الأحاديث النبوية: HadithAPI ( الكتب الستة وغيرها) وموسوعة الدرر السنية.
